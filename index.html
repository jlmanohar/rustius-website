Unified Remote Workspace

All Three Core Remote Protocols in One Native Binary

Stop switching between three clunky legacy tools. Rustius brings terminal, file transfer, and remote desktop into a unified tabbed workflow.

Pure-Rust SSH & PTY

Powered by russh and portable-pty. Includes automatic keepalive, seamless resize reflow, and full scrollback preservation across tab switching.

  • xterm.js full ANSI/color terminal
  • Local PowerShell, Cmd, & Bash shells
  • Public key, passphrase, and password auth

Dual-Mode SFTP

Browse remote files directly beside your active SSH session. The MobaXterm-style navigator follows your shell's working directory in real time as you cd.

  • Live Terminal Directory Follow/Sync
  • Dedicated dual-pane bulk manager
  • Drag & drop uploads and quick downloads

Canvas Remote Desktop

Connect to Windows servers and virtual desktops. Powered by IronRDP streaming frames directly to HTML5 Canvas with fluid mouse and keyboard input forwarding.

  • Network Level Authentication (NLA)
  • Full keyboard and mouse capture
  • Low CPU and memory consumption
Engineering Highlights

Built for Speed, Privacy & Simplicity

Every detail is designed according to the Vercel Geist design system: high contrast, zero clutter, and rock-solid privacy.

Native OS Keyring Security

Credentials, passwords, and private key passphrases are stored in Windows Credential Manager, macOS Keychain, or Linux Secret Service. Fallback local vault encrypted with Argon2id and ChaCha20-Poly1305.

Zero-Install Portable Mode

Follows VS Code portable mode conventions. Simply place a data/ folder alongside the executable to store all sessions, connections, and configs on a USB thumb drive.

Zero Electron Memory Bloat

Powered by Tauri v2 with the OS webview (WebView2 on Windows). Consumes under 40MB of RAM at idle, starts instantly in under 50ms, and ships as a tiny ~8MB installer.

Custom Frameless Window Chrome

Clean typography-driven UI with native window dragging, seamless window minimization/maximization, and grouped connection trees with environment tags (Production, Staging, Dev).

Open Source Architecture

Modular Rust Workspace

Rustius is organized into distinct, focused Rust crates with separation between protocol drivers and the UI shell.

rustius-core

Connection management, TOML configuration, and OS Keyring vault abstractions.

rustius-ssh

Pure-Rust SSH client (russh) and SFTP file operations (russh-sftp).

rustius-rdp

IronRDP protocol negotiation, TLS 1.3 encryption, and canvas frame decoding.

rustius-terminal

Cross-platform local PTY process spawning via portable-pty.
